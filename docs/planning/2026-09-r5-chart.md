# Round 5 — Chart split + new series types

Status: complete

## Goals

- Split the ~640-line `Chart.tsx` monolith into modules.
- Add series types: `gauge`, `radar` (spider), `funnel`, `heatmap`.
- Verify and test stacked series (implementation pre-dated this round).
- Keep the public API (`Chart`, `ChartProps`, `ChartSeries`, `SeriesClickArgs`)
  unchanged for `lib/main.ts` consumers.

## Structure

| File                                   | Role                                                                              |
| -------------------------------------- | --------------------------------------------------------------------------------- |
| `lib/components/Chart/chart-shared.ts` | Types, `PALETTE`, `niceScale`, `pointsFor`, `ChartRenderContext`, axis-type sets  |
| `lib/components/Chart/renderers.tsx`   | Per-type renderers + `renderSeries` dispatcher                                    |
| `lib/components/Chart/Chart.tsx`       | Shell: props, tooltip state, axes/gridlines, legend, a11y table; re-exports types |

Every series `<g>` carries `data-chart-type={ser.type}` for tests/e2e.

## Decisions

- **Axis visibility**: value ticks/gridlines only for
  `VALUE_AXIS_TYPES` (line, area, bar, column, scatter, bubble); bottom
  category labels additionally for `heatmap`; pie/donut/gauge/radar/funnel
  render without axes.
- **Gauge value** = sum of the series points; scale (min/max) comes from the
  usual value axis (`valueAxis.max` recommended); 270° arc from 135°.
- **Heatmap** adds optional `ChartSeries.rowProperty` (y dimension); cell
  fill opacity ramps per-series min→max; falls back to a single `All` row
  when `rowProperty` is omitted.
- **Radar** uses max(3, categories) spokes, rings at 25/50/75/100%,
  non-negative values clamped to `scale.max`.
- **Funnel** rows follow data order, trapezoids taper to the next row's
  width, labels always visible (`cat · value`).
- Dead `stackSums` map (write-only) removed during the split; pie totals
  computed inline per series.

## Review fixes (post-implementation)

Code review of the round flagged four issues, all fixed:

1. **Stacked bars overflowed the plot** — value scale only considered
   individual point values, so stack totals (the normal stacking case)
   rendered above the SVG origin. The `values` memo now includes
   per-category stack totals; stacked test asserts `y >= 0`.
2. **Heatmap row dimension absent from the a11y table** — the hidden
   fallback table (referenced by `aria-describedby`) now folds `rowProperty`
   into the category cell (`EU / Mon`).
3. **Multi-series radar painted the grid over prior series** — rings/spokes
   are per-chart, not per-series; hoisted into `renderRadarGrid(ctx)`,
   rendered once before all series groups when any radar series exists.
   Series groups now contain only their polygon/points/labels.
4. **Gauge click reported the series title as `category`** — now passes the
   first point's category (e.g. `Q1`), matching every other renderer.
